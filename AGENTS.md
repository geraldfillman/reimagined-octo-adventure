## Data Readiness Preflight

Run before any daily/premarket/preclose/EOD/monitoring/briefing report. `READY` proceeds; `WARN` proceeds with the warning carried into output (`midday` is the policy-allowed warn slot); `BLOCKED` stops until refreshed or explicit user-approved `--allow-stale`. Policy: `daily`/`premarket`/`eod` block on stale required inputs; `preclose` blocks only for required market/vol inputs (supporting inputs warn). Never use `--stale-ok`/`--allow-stale` without explicit approval.
